1. Zero Coleta de Dados Pessoais pelo Digitinho Galaxy

O Digitinho Galaxy é um jogo web estático executado integralmente no navegador do jogador (client-side). O projeto não possui servidores de backend próprios, banco de dados remoto, formulários de cadastro ou sistema de contas de usuário. Nenhum dado pessoal (como nome, e-mail, documento ou telefone) é solicitado, coletado, processado ou comercializado pelo desenvolvedor.

2. Armazenamento Local no Dispositivo (HTML5 LocalStorage)

Todo o progresso do jogo — incluindo pontuação, slots de salvamento, palavras desbloqueadas na Biblioteca, conquistas obtidas, preferências sonoras, dificuldade e tema visual — é armazenado exclusivamente no armazenamento local do seu próprio navegador (localStorage). Essas informações jamais saem do seu aparelho e podem ser apagadas permanentemente a qualquer momento limpando os dados do navegador ou excluindo slots no próprio jogo.

3. Infraestrutura de Hospedagem e Registros Técnicos do GitHub Pages

O Digitinho Galaxy é hospedado como um site estático na infraestrutura do GitHub Pages (operada pela GitHub, Inc. / Microsoft). Ao acessar a página, os servidores do GitHub podem processar e registrar automaticamente metadados técnicos de conexão — tais como endereço IP, data/hora da requisição, navegador (user-agent) e URL solicitada — para fins estritos de segurança, manutenção de infraestrutura e prevenção de abusos, em conformidade com a Declaração de Privacidade do GitHub. O desenvolvedor do Digitinho Galaxy não tem acesso a registros brutos de IPs nem utiliza esses dados para identificar ou rastrear jogadores.

4. Zero Cookies de Rastreamento ou Analítica de Terceiros

O jogo não utiliza cookies de publicidade, Google Analytics, pixels de redes sociais ou ferramentas de telemetria e perfilamento comportamental de terceiros. A experiência é 100% voltada ao treino de digitação e diversão arcade.

5. Conformidade com a LGPD e Diretrizes da ANPD

Em observância à Lei Geral de Proteção de Dados Pessoais do Brasil (Lei nº 13.709/2018 - LGPD) e às orientações da Autoridade Nacional de Proteção de Dados (ANPD), o projeto adota estritamente os princípios de finalidade, necessidade, não discriminação e minimização de dados. Como o desenvolvedor não realiza tratamento de dados pessoais dos jogadores, nenhuma informação pessoal é comercializada, compartilhada ou transferida a terceiros.

6. Código Aberto, Transparência e Auditoria

O Digitinho Galaxy é um projeto de código aberto disponibilizado sob a Licença MIT. Qualquer pessoa pode inspecionar, auditar e verificar o código-fonte integral no GitHub para atestar a ausência total de rastreadores ocultos, telemetria ou coleta remota de dados.
